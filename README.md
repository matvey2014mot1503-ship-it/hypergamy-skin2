# Hypergamy Skin

Клиентский Fabric-мод для Minecraft **1.21.4**. Показывает всех игроков со скином `hypergamy`
(с любыми скинами, в броне или без). Другие игроки ничего не замечают.

## Управление
Клавиша **K** (меняется в «Управление» → «Hypergamy Skin») включает и выключает скин.
Над хотбаром появляется сообщение о состоянии.

## Установка
1. Fabric Loader для 1.21.4: https://fabricmc.net/use
2. Fabric API для 1.21.4
3. Файл `hypergamy-skin-*.jar` положить в `.minecraft/mods`

## Где взять .jar
Вкладка **Actions** → последний запуск `build` → Artifacts → `hypergamy-skin`.
Или создайте релиз тегом `v1.1.0`, тогда jar появится во вкладке **Releases**.

## Своя картинка
Замените `src/main/resources/assets/hypergamy/textures/skin.png` (64x64) и закоммитьте.
